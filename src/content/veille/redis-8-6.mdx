# Résumé

La version 8.6 de Redis a été mise à disposition pour les systèmes Enterprise Linux et Fedora. Cette version améliore la stabilité du SGBD et prépare le terrain pour des mises à jour fonctionnelles majeures sur les modules intégrés tels que Redis Bloom et Redis TimeSeries, en optimisant la gestion de la mémoire.
