# Résumé

Les espaces de travail "Serverless" de Databricks sont officiellement passés en disponibilité générale (GA). Préconfigurés avec du calcul et du stockage par défaut, ils offrent une expérience SaaS entièrement managée qui simplifie considérablement la configuration initiale pour les équipes Data, accélérant ainsi les déploiements de pipelines massifs.

# Type

Big Data / Plateforme
