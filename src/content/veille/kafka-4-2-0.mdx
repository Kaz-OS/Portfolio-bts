# Résumé

La fondation Apache a publié Kafka 4.2.0. Cette version majeure apporte de nouvelles améliorations opérationnelles pour les environnements à très grande échelle. Elle consolide la stabilité du mode KRaft (qui a remplacé ZooKeeper) et ajoute des optimisations de performances pour les flux d'événements distribués en temps réel.
