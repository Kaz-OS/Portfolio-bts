# Résumé

Redis annonce une série de nouveautés de printemps, avec un fort accent sur l'écosystème IA. La mise à jour introduit "Redis Iris" (un agent fournissant du contexte en temps réel), "Redis LangCache", et affirme le rôle de Redis non seulement comme magasin clé-valeur ultrarapide, mais comme brique d'infrastructure centrale pour les applications d'IA générative.
